# Mapa de Ocorrências (Satélite) — Postos x Registros

Este app lê 2 abas publicadas como CSV no Google Sheets:
- POSTOS: posto, local (opcional), lat, long
- OCORRÊNCIAS: posto, natureza, datahora (DD/MM/AAAA HH:MM)

Recursos:
- mapa satélite (Esri)
- heatmap com sensibilidade (Log/Bruto/Raiz/Gamma + cap)
- filtro por período e natureza
- 1 ponto por coordenada (agrupado) com popup detalhado
